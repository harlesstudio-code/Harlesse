Spesifikasi File

Batas Teknis Audio Roblox

  • Format: .mp3, .ogg, .wav, .flac
  • Ukuran maksimal: 20 MB per upload
  • Durasi maksimal: 7 menit (setelah speed diubah)
  • Sample rate: ≤ 48 kHz
Biaya & Kuota

Kuota Bulanan Gratis

  • Biaya upload: Gratis (0 Robux)
  • Akun belum ID-Verified: 10 audio / bulan
  • Akun sudah ID-Verified: 100 audio / bulan
  • Status default audio: Private ke User/Group target
Cara Setup API Key

Langkah Cepat Open Cloud

  1. Buka Creator Dashboard → Open Cloud → API Keys.
  2. Klik Create API Key, tambahkan sistem Assets dengan izin Read & Write.
  3. Masukkan IP kamu jika perlu, simpan key lalu tempel di form di atas.
